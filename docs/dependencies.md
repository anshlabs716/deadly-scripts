# Dependencies

These scripts intentionally use only tools that are present on a standard
installation of the target system.

- **Bash** and standard Linux coreutils for the shell scripts
- **Windows Script Host** for `virus.vbs`

No third-party packages are bundled. See
[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) for attribution and
[docs/platform-compatibility.md](platform-compatibility.md) for platform notes.
