## ⚠️ IMPORTANT WARNING

**These scripts are intentionally disruptive and can interfere with normal system operation.**

Only use them on systems you own or have explicit permission to test.

Do not use them to disrupt another person's computer, work, school environment, or data.

---

## 📖 About

**deadly-scripts** is a collection of system-disruption experiments written in different scripting languages and targeted at different operating systems.

The repository was created before [`invoke-bsod`](https://github.com/anshlabs716/invoke-bsod/tree/main) and contains several older experiments.

The project explores what scripting environments can do when interacting with operating-system functionality.

---

## 🧩 Relationship to invoke-bsod

This repository is related to **[invoke-bsod](https://github.com/anshlabs716/invoke-bsod/tree/main)**.

While `invoke-bsod` focuses specifically on **PowerShell and Windows crash experimentation**, `deadly-scripts` contains older implementations written in other scripting formats and targeting different environments.

### Projects

| Project | Language | Target | Purpose |
|---|---|---|---|
| [`invoke-bsod`](https://github.com/anshlabs716/invoke-bsod/tree/main) | PowerShell | Windows | Windows crash experimentation |
